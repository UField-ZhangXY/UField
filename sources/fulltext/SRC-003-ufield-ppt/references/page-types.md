# 页型目录（V3 母版版式库 · 16 版式）

源文件在 `templates/v2/`（目录名保留，内容已是 V3 的 16 版式集）。复制到项目 `slides/` 后**重编号**并替换占位文案。`NN` 决定最终页码（slidep 页码从 0 起，故 `01_*.slide` → index 0）。

> **通用约定（内容页 06–12、14）**：整页 `flexDirection: 'row'` —— 左侧固定 **86px 边条**（`assets/elements/side_bar.png` + 两列竖排 slogan），右侧内容区 `flex:1, padding:44`；**Logo 绝对定位** `top:38, right:44`（96×49），**不要放进页头 flex 行**；页脚 `right:48, bottom:24` 写 **`@PAGE@ / @PAGES@`**（构建链路 `pagenum.py` 会替换成 PowerPoint 页码域，增删页自动更新）。满幅页（01/04/05/13/15/16）**不开边条**。
> 选用原则：**一套 deck 里同类版式别重复堆砌**；典型编排见文末。

### 01_cover_dark —— 满幅封面（地球 + 橙 U 弧）★ 默认主封面
满幅 `cover_earth.jpg`。居中：`ufield_logo_shadow`（133×71 白影 Logo）→ 主标题 `58px 方正姚体 letterSpacing 10` → 橙色短线 72×4 → 副标题 `18px`；左下落款 `14px`。标题块 `top:172`。
- 深色底 Logo **只用 `ufield_logo_shadow.png`**（白影贴纸），**不要用白色胶囊衬底**。

### 02_cover_light —— 白境封面
轻量封面（左文右图）：左侧橙顶标 + 青绿大标题 `52px` + 副标题 + 三色圆点行 + 落款；右侧 `cover_u_arc` 方图。

### 03_toc —— 目录点阵
双栏大编号导航（可 4 / 6 章）。大标题「目录」`34px` 右上 Logo `110×56`；每栏条目 = 半透明大数字 `40px`（青/橙/深青/灰四色轮转）+ 章节名 `22px` + 一句概述 `14px`。

### 04_section_gradient —— 章节页·渐变深底（V2 血统）
`linear-gradient(135deg,#0E2A47,#024A3C)` 底 + 右侧散布 4 个光点；左侧 `150px` 半透明巨数字 `01`；标题组 `left:104, top:424`：橙短线 56×5 + 章节标题 `44px 方正姚体` + 引导语 `17px`。

### 05_section_image —— 章节页·满幅图（C3 血统）
满幅 `circle_sprout.jpg`（`cover`）底。居中标题组 `top:196`：`C H A P T E R · 0 1` 小标签 → 章节标题 `54px` → 橙短线 72×4 → 引导语 `17px`；全部带 `textShadow` 保证白字压图可读。
- **选 04 还是 05**：有合适满幅图 → 05（沉浸感强）；无 → 04（更轻）。

### 06_image_points —— 图文页（左图右三要点）
展开一个主题的 2–3 个要点。左侧圆角大图（`560×400 cover, borderRadius 16`）+ 图注；右侧 `01/02/03` 编号要点（青/橙/深青），每条 = 标题 `20px` + 描述 `15px`。
- 方图源用 `contain`。容器内若还有图注，图片高度再留 ~30px。

### 07_points_2x2 —— 四观点 2×2
四个平行观点/要点（2×2）。每条 = 圆点徽标（30px 圆底 + 12px 实心点，四色轮转）+ 标题 `20px` + 描述 `14px`。适合「四个视角」「四条原则」。

### 08_cards_3 —— 三色域卡片
三个并列概念/维度。青/橙/靛三张浅底圆角卡片（`borderRadius 18, padding 30`），每张 = 圆点 + 编号 + 标题 `21px` + 短横线 + 正文 `14px/1.75` + 关键词行 `13px`。

### 09_cards_icon —— 三栏图标卡片（V1 血统）
三个并列概念，比 08 更精致：白底卡片 + **顶边 5px 色条**（青/橙/深青）+ 圆形图标底（60px 圆，`FAIcon` seedling / comments / compass）+ 标题 `20px` + 橙短线 + 描述 `14px`；卡片 `boxShadow`。
- 图标名走 `FAIcon`（FontAwesome），换概念时替换 `name` 与 `fill`。

### 10_u_flow —— U 型流程（5 节点 U 弧）★ U 型理论专属
内联 `<svg>`（`viewBox '0 0 1020 470'`，**width/height 与 viewBox 1:1，避免缩放错位**）画 U 弧（`M230,150 C417,430 603,430 790,150`，青 9px 主笔 + 橙 3px 覆线）；5 个节点圆点（r=24）**圆心精确落在曲线上**（贝塞尔 t=0/0.25/0.5/0.75/1 → `(230,150) (370,308) (510,360) (650,308) (790,150)`，青/白描边/橙/白描边/青）；标签 17px+12px：1/5 号在**圈外侧**（left 64 / 826, top 130），2/3/4 号在**曲线下方**（top 355/398/355），全部避开曲线。
- 讲 U 型理论、7 步旅程、任何"下沉再上升"流程时用。

> **线性图形两条铁律**（2026-10-11 定）：① **线必须穿过圆心** —— 节点坐标用贝塞尔参数 t 精确计算（五等分 t=0,.25,.5,.75,1 的 x/y 代入贝塞尔式），不要目测摆点；② **字不能被线压** —— 标签统一放曲线的**外侧空白带**（U 弧 = 两端圈外侧 + 弧底下方），摆完逐点验算标签矩形与曲线在该 x 区间的 y 范围无交集。

### 11_step_timebox —— 步骤·时间盒页（C3 血统）★ 工作坊/流程专用
左 `flex:1`：**橙色时间胶囊**（`rgba` 橙底圆角 + 白字 `00:00 – 00:02`）+ 时长说明 + `01/02/03` 编号要点（编号 22px 青/橙/深青，标题 `19px`，描述 `14px` 内含**橙/青高亮词**）；右侧 380px 放`unity_circle` 等手绘图（`360×360 contain`）+ 图注。
- 做工作坊时间表、流程分步、逐环节说明时首选。

### 12_tool_map —— 工具地图（3×3 密集格）
一张图看清全部工具/要点。3 列 × 3 行小卡（`height 108`，底 `#EAF4F0`/`#FBF1E2`/`#EDF0F5` 分列），每卡 = 色点 + 工具名 `15px` + 一句说明 `12px`。页头带副标题 `15px`。
- 适合「工具全景」「要素清单」等需要**一张图盛下多项**的场合。

### 13_big_type —— 大字转场页
满幅 `dark_cover.png`（`cover`）底 + `96px` 巨型词（`方正姚体 letterSpacing 24`，如「自然流现」）+ 橙短线 90×4 + 一句点题小字 `16px`。大留白，做呼吸/章节内视觉锤。

### 14_timeline —— 河流时间线
中部横放 `flow_line.png`（`1200×280 cover`）当河流，其上 4 个节点圆点（青/深青/橙/靛，3px 暖白描边），配上下交错阶段标签（标题 `17px` + 描述 `13px`）。
- 坑：标签若落在笔触上扬/下沉处会压字，**上下标签要错开到笔触空白带**。

### 15_quote —— 金句页
一句点亮全场的话。左 `96px` 半透明引号 + 楷体金句 `30px/1.9` + 橙短线 + 出处 `15px`；右下角手绘方图（`quote_figure` / `unity_circle`，`contain`）；左上 Logo `110×56`。
- 金句 20–40 字（超 3 行会与图挤），**去掉所有 letterSpacing**。

### 16_closing —— 满幅结尾（地球 + 人群光点）
满幅 `earth_people.png` 底 + 居中「谢谢聆听」`64px letterSpacing 20` + 橙短线 + slogan 小字 `17px`；左下落款 `14px`。与 01 首尾呼应。

## 典型 16 页编排（可直接套）

| 页 | 版式 | 内容 |
|---|---|---|
| 01 | 01_cover_dark | 满幅封面 |
| 02 | 03_toc | 目录（4 章） |
| 03 | 04_section_gradient 或 05_section_image | 章节 01 |
| 04 | 06_image_points | 章节 01 展开 |
| 05 | 15_quote | 章节 01 金句 |
| 06 | 04_section_gradient | 章节 02 |
| 07 | 08_cards_3 | 章节 02 展开 A |
| 08 | 09_cards_icon | 章节 02 展开 B |
| 09 | 04_section_gradient | 章节 03 |
| 10 | 10_u_flow | 章节 03 展开（U 型） |
| 11 | 11_step_timebox | 章节 03 展开（流程） |
| 12 | 12_tool_map | 章节 03 工具全景 |
| 13 | 13_big_type | 章节 04 转场／点题 |
| 14 | 14_timeline | 章节 04 历程 |
| 15 | 07_points_2x2 | 本讲小结 |
| 16 | 16_closing | 满幅结尾 |

> 页数可伸缩：短内容（≤8 页）省去部分章节页，走 封面 → 目录 → 若干内容页 → 金句 → 结尾；长内容在章节内叠加多个内容页。
> 页脚统一写 `@PAGE@ / @PAGES@`（pagenum.py 域化后页码自动更新、总页数取构建时页数）；用带边条的内容页时记得整套保持一致。
