# UField 演示设计系统

UField 演示的视觉基调：**温暖留白 + 手绘色域 + 青绿主色 + 暖橙点缀**。克制、有呼吸感、有手作温度，不堆满、不用生硬几何色块。

> 版式库版本 **V3.0**（2026-10-11 定稿）= V2 深色书档骨架 + V1 的 U 型流程页 / 三栏图标卡片 + C3 参考件（《案例诊断 V1.0》）的流程语法与视觉资产。`templates/v2/` 目录名保留兼容，内容已是 16 版式 V3 集。

**用色纪律**：单页 ≤3 主色（青 + 橙 + 一个第三色），三色域卡片/工具地图必须按「青 → 橙 → 靛」顺序。深色页文字一律白色系（`#FFFFFF` / `rgba(255,255,255,0.85~0.92)`）。

**青橙分工（V3 强调语法）**：**青绿管「结构」**（编号、竖条、分隔线、卡片描边、圆点），**暖橙管「焦点」**（高亮词底纹、时间胶囊、重点短线、需一眼落到的位置）。两者不混用——把 C3 的纯黄高亮转译成品牌橙实心块，既"跳"又保品牌。

## 二、字体与字号

- **V3 字体三件套**：大标题（≥40px）`fontFamily: '方正姚体'`；正文/标签 `fontFamily: '幼圆'`；金句 `fontFamily: 'KaiTi'`。
  - ⚠️ 幼圆 / 方正姚体随中文 Office 发行，**渲染机（CI / LibreOffice 容器 / 无中文 Office 的机器）常缺字而回退**，版式不塌但气质打折。本机（装中文 Office，C3 即用这两款）显示正常。
  - **目标机器不确定时**：退回「系统默认字体」策略（不指定中文字体名，渲染最稳），此时只保留金句楷体。
- 字号阶梯（1280×720 画布）：

| 用途 | 字号 |
|---|---|
| 满幅封面主标题 | 58（`letterSpacing` 6） |
| 浅色封面主标题 | 52 |
| 章节页巨型页码 | 150（`rgba(255,255,255,0.14)`） |
| 大字转场页 | 96（`letterSpacing` 24） |
| 满幅图章节标题 | 54；渐变章节标题 44 |
| 页面标题 | 30 |
| 侧栏竖排 slogan | 32（`lineHeight` 1.18，见下） |
| 金句 | 30（`lineHeight 1.9`） |
| 卡片/要点标题 | 19–21 |
| 正文/描述 | 14–15（`lineHeight 1.6–1.75`） |
| 页脚/图注 | 12–13 |

**硬规则**：≤15px 文字一律不加 `letterSpacing`（会被裁字）；`Image` 的 `width`/`height` 必须成对给。

## 三、栅格与留白

- 画布 `1280 × 720`。
- **内容页双栏结构（V3）**：左侧固定**边条 86px** + 右侧内容区（`padding: 44`）。整页 `flexDirection: 'row'`。
- 内容页页头：标题在左，Logo **绝对定位** `top: 38, right: 44`（**不要放进 flex 页头行**——带副标题的页会把 Logo 撑低 ~10px，导致各页 Logo 不齐，见 engine-guide）。
- 标题下一条 3px 分隔线（内容页常用 `#EC9804`，也可用 `#018985`/`#02604F`）。
- 左右双栏：`gap: 44~48`；三栏卡片：`gap: 28~32`。
- 页脚统一 `position: absolute, right: 48, bottom: 24`，`12px`；DSL 里写 `@PAGE@ / @PAGES@` 占位即可（**masterize 会剥离页面页脚，改为版式层页码域**，增删页自动更新；OOXML 无总页数域，故只显示页码）。

## 四、左侧边条（V3 签名元素）

- 素材 `assets/elements/side_bar.png`（134×1125，按 720 高落位 = **86px 宽**）；渐变 teal `#338288` → 深绿 `#22695F` → 墨青 `#206873`，右缘自带浅青高光。
- 其上叠**两列竖排 slogan**（文字层，素材不带字）：每个 `<Box>` 定宽 40、`left: 18`、`textAlign: 'center'`、逐字换行；`fontSize 32` / `color rgba(255,255,255,0.8)` / `fontFamily '幼圆'` / `lineHeight 1.18`。
  - 上行「陪育商业新生态」`top: 29`；下行「催化集体创造力」`top: 363`（近乎上下居中，上下留白对称）。
  - **每套演示可整体替换文字，素材本身不动**。
- **开/关**：全部内容页（06–12、14）开；封面、章节、大字、金句、结尾等满幅/呼吸页关。
- **DSL 与版式的关系**：模板 DSL 里照常画侧栏 + slogan（自包含、可独立预览）；跑 `masterize` 后会收拢到「内容页·白底+侧栏」版式层 —— **换 slogan / 换 Logo / 调底色只改版式一处，全套内容页跟着变**。
- 让整套 PPT 翻起来有「一条青绿脊线」贯穿，识别度极高。

## 六、版式基因

- **深色书档结构**：第 1 页深色满幅封面 + 末页深色满幅结尾，首尾呼应；中间内容页一律暖白底 + 左侧青绿边条。
- **两套章节页并存**：渐变深底（`04_section_gradient`，V2 血统）｜满幅图（`05_section_image`，C3 血统，图带白字+阴影）。按素材有无选。
- **章节目录**：双栏大编号灰数字（`03_toc`，可 4 或 6 章）。
- **内容页家族**：图文页（左图右要点）/ 四观点 2×2 / 三色域卡片 / 三栏图标卡片 / U 型流程（5 节点 U 弧）/ 步骤·时间盒 / 工具地图（3×3 密集格）。
- **金句页**：大留白，左 96px 半透明引号 + 楷体金句 + 橙短横线 + 出处，右下角手绘方图。
- **大字转场页**：满幅暗底 + 96px 巨字 + 橙短线，做呼吸/点题。
- 详细页型 DSL 骨架见 [page-types.md](page-types.md)；母版化与减重见 [engine-guide.md](engine-guide.md)。
