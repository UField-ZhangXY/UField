# 内容 → 演示结构

把任意素材（大纲、文档、srt 字幕、网页、会议笔记）转成一套有叙事骨架的 UField 演示。

## 一、先定三件事

1. **一句话主张**：这次演示要让人记住什么？（做封面副标题 + 结尾 slogan 的依据）
2. **章节数**：一般 **3–5 章**。每章 2–3 页（章节页 + 1–2 展开页 + 可选金句）。
3. **总页数**：短内容 8–12 页，标准 14–18 页，长内容 20+ 页。

## 二、叙事骨架（V3 默认，深色书档）

```
封面（满幅 01，深色）
└─ 目录（03，列章节）
   每章 × N：
   ├─ 章节页（04 渐变深底 ／ 05 满幅图 二选一）
   ├─ 展开页（06 图文 / 07 2×2 / 08 三色卡片 / 09 图标卡片 /
   │          10 U 型流程 / 11 时间盒 / 12 工具地图 / 14 时间线，按内容形态选）
   └─（可选）金句页（15）或 大字转场页（13）
本讲小结（07_points_2x2 四点）
结尾（满幅 16，与封面呼应）
```

> 内容页（06–12、14）统一带**左侧青绿边条**——整套翻起来是一条贯穿的脊线。

## 三、内容形态 → 版式映射

| 内容形态 | 选用版式 |
|---|---|
| 并列的 2–3 个要点，且有一段引子/叙事 | `06_image_points`（左图右要点） |
| 四个平行观点 / 四条原则 | `07_points_2x2` |
| 三个并列概念/维度（朴素版） | `08_cards_3`（三色域卡片） |
| 三个并列概念（要更精致的图标卡片） | `09_cards_icon`（三栏图标卡片） |
| U 型旅程 / 任何「下沉再上升」的流程 | `10_u_flow`（5 节点 U 弧） |
| 工作坊时间表 / 分步骤流程（带时间盒） | `11_step_timebox`（步骤·时间盒） |
| 工具全景 / 要素清单（一图盛多项） | `12_tool_map`（3×3 密集格） |
| 阶段、历程、流程、时间线 | `14_timeline`（河流时间线） |
| 一句有分量的话 / 引用 | `15_quote`（金句页） |
| 章节转场 / 视觉锤 / 一个词点题 | `13_big_type`（大字转场页） |
| 讲一个「图」或关系（如 U 型、三形状） | `06_image_points` + `source_diagram` 等示意图 |
| 章节开篇（有满幅图 → 沉浸 / 无图 → 轻量） | `05_section_image` ／ `04_section_gradient` |

## 四、写作要点

- **标题是观点，不是标签**：写「友情是变革的源头」而不是「关于友情」。
- **每页一个中心**：要点 2–3 条，每条 1 行标题 + 1 句描述（≤30 字）。
- **金句要短**：20–40 字，用楷体，配手绘方图。
- **章节引导语**：一句话说清「这一章讲什么、为什么重要」。
- **高亮要克制**：一页里橙/青高亮词 1–2 处，只落在真正要一眼看到的地方（步骤页、要点页）。
- **忠于素材**：字幕/文档里的具体表述（人名、数字、原话）要保留，不要泛化；中英混排素材以中文为主体，英文术语可括注。

## 五、字幕（srt）→ 结构 的专门做法

1. 通读，**删掉口语填充**（"然后""就是""哈"、重复与自我修正），留下观点句。
2. 按**语义转折**切章：一个话题讲完转入下一个，就是一个章节边界。
3. 每章从字幕里**摘一句最有力的话**做金句页。
4. 英文段落用中文译文为主；关键术语保留英文（如 Otto Scharmer、Theory U）。
5. 若字幕只覆盖了开场一部分（讲者话没讲完），用「本讲小结」页收束已讲内容，并可在副标题里点出「接下来要展开的方向」，**不要杜撰未讲的内容**。

## 六、模式 B（美化已有 PPT）的输入处理

用 python-pptx 读出原 pptx 每页的文本：

```python
import pptx
p = pptx.Presentation('old.pptx')
for i, s in enumerate(p.slides):
    for sh in s.shapes:
        if sh.has_text_frame and sh.text_frame.text.strip():
            print(i, sh.text_frame.text.strip()[:80])
```

把提取出的文本当作「内容源」，按上面第二、三节重建成 UField 版式。原 PPT 的图若可复用，导出后放进项目 `assets/`。
