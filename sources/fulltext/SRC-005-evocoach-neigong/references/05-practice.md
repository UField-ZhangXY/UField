## 练习一：停止凑合清单（核心稳定性入口）

| 项 | 内容 |
|---|---|
| 出处 | 模块一（13）`[M1-13]` |
| 时长 | 课后作业，约 30 分钟 |
| 分组 | 独立完成 → 次日向助教小组汇报 |
| 教材 | 核心稳定性手册「停止凑合」板块 |

**步骤**
1. 选一个领域（工作 / 关系 / 生活 / 物理空间）
2. **列出至少 10 件正在妥协凑合的事**
3. **选一件，只走出第一步**（不需要全部解决）
4. 次日在助教小组分享完成后的感受

**示例梯度**（帮助学员理解"最小动作"）
- 小：修漏水的水龙头、擦掉墙上一直没清理的指印
- 大：发现房子地段不对、拖了五年 → **第一步只是打电话给中介做估价**

> 价值提示：「完成一件你凑合了很久的小事，会释放出大量被消耗的能量，你会惊讶于能量提升的幅度。」`[M1-13]`

## 练习二：未完成事件梳理

| 项 | 内容 |
|---|---|
| 出处 | 模块二（06）`[M2-06]` |
| 时长 | 每人分享 2–5 分钟（按小组人数调节） |
| 分组 | 回到 TA 小组，4–6 人 |
| 产出 | 每人写下 1–2 个真正卡住自己的未完成事件 |

**步骤**
1. 梳理生命各领域中的未完成事件：**物理环境 / 关系 / 工作 / 家庭 / 项目**
2. 找出 **1–2 个**明确卡住自己、至今仍在影响自己的
3. 在三个选项中明确选一个：立刻去做 / 彻底放下 / 授权他人
4. 明确自己的完成计划，向小组坦白分享
5. **教练/助教负责跟进**

**要求**：「一定要对自己坦诚，不要害羞，不要试图掩饰。」`[M2-06]`

**验收标准**：不是"列了多少条"，而是**承诺的那 1–2 件是否真的发生**。

## 练习三：能量／自豪感放大练习

| 项 | 内容 |
|---|---|
| 出处 | 模块二 · 内在小孩情绪课题（Lisa） |
| 时长 | 现场带领，10–15 分钟 |
| 分组 | 全体学员同步做，之后与身边的人分享 |

**步骤**
1. 找到自己身上**感受到自豪的位置**（在身体中的位置）
2. 想一件让自己自豪的事
3. 想象有一个类似**空调调节按钮**的开关
4. 慢慢把自豪感**调大**，让它充满整个身体，浓烈到要溢出皮肤
5. 把溢出的自豪感**传递给身边的人**，让彼此的自豪感交融

**要破除的信念**：很多人认为「如果我放大自己的能量，就会挤占别人的空间」——实际所有人都可以同时放大，能量可以充满整个空间，不会有人被挤出去。不需要为了给别人腾空间而活在渺小里。

> 教学提示：这个练习的关键是**当场点破"挤占"这个限制性信念**，让学员自己觉察到它。

| 项 | 内容 |

## 组织方式：小组怎么组（可复用）

| 项 | 内容 | 出处 |
|---|---|---|
| 人数 | **3–6 人**小型学习小组 | `[M3-39]` |
| 理由 | 集体练习比独自练习更容易坚持——**小组成员之间会互相做出承诺** | `[M3-39]` |
| 角色 | 彼此支持、互相教练 | `[M3-39]` |
| 要求 | 学员先自行识别「核心稳定性多个板块中和自己当下最相关的一个方向」，再优先投入 | `[M3-39]` |

**方向清单**（帮助选择优先项）：设定边界 / 事务收尾 / 生活平衡 / 财务稳定 / 与身体的关系 / 需求表达。

## 讲师对练习成效的原话（可作动员）

- 「教练是需要不断练习的自律性技能，哪怕读上千本教练书籍，也不如亲自实践收获的知识多。」
- 「哪怕已经觉得自己了解某部分内容，也要勤奋、精准、彻底地再完成一遍练习。」
- 「不需要追求完美，所有教练都会犯错，在试错中学习就是正常的成长路径。」
- 「通过自己的实践，比我们能教你的，你要收获的多得多。」

（均出自 `[M3-39]`）
