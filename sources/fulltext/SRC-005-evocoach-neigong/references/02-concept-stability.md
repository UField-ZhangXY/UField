# 核稳修炼 · 核心稳定性概念卡

> 教练内功 · **第一练**（能力线名称：核稳修炼）
> 出处：第1模块（13）核心稳定性讲解（Lisa，37min）· 第1模块（15）停止凑合（Zoran+Lisa，53min）· 第2模块（06）通过完结未完成事件活在当下（Zoran，30min）· 第3模块（39）练习讲解与实践要求（Zoran，29min）
> 篇目 ID 简写：`[M1-13]` `[M1-15]` `[M2-06]` `[M3-39]`

## 一、一句话定义

**核心稳定性 = 既能深深扎根、又能保持流动的能力：外部冲击来时可以吸收、可以晃动，但能快速回到中心，不被带走。**

它是进化教练体系里的**托底基础能力**，也是个人成长的重中之重——**核心不稳，成长越快坍塌越快**。`[M1-13]` `[M3-39]`

## 二、三级定位（别只当成一个"心态练习"）

| 层级 | 含义 | 出处 |
|---|---|---|
| ① 个人成长的根基 | 只有根基稳，才能承载指数级成长；否则成长越快越容易坍塌 | `[M3-39]` |
| ② 合格教练的托底能力 | 客户的情绪与信息只是**流经**自己，不被带走，才能保持中正 | `[M1-13]` |
| ③ 可交付的教练工具 | 手册可作自我教练，也可作为工具给来访者布置作业，在两次约谈之间完成 | `[M3-39]` |

> 实证：一位老学员连续四年做核心稳定性练习，生命实现指数级成长。教学团队多年下来能清晰区分「做过」与「没做过」的学员，差异天壤之别。`[M3-39]`

## 三、隐喻库（讲给来访者时最好用）

| 隐喻 | 说明 | 出处 |
|---|---|---|
| **深根大树** | 根扎得越深，反而越灵活——风暴来了可以摇摆，雨来、暴晒都扛得住 | `[M2-06]` |
| **竹子** | 巴厘岛用竹子建房，比钢筋更坚固，因为它**能弯曲吸收能量** | `[M1-13]` |
| **不倒翁 / 竹叶上练功** | 不管怎么晃都不会倒；不管经历多少起落都保持中正 | `[M1-13]` |
| **网球** | 跑动中先找到身体中心的稳定支点，站定再挥拍，一下变轻松 | `[M1-13]` |
| **太极 / 接篮球** | 硬手会把球弹飞；软手吸收球的能量后，再决定把球送到哪里 | `[M1-13]` |
| **导管** | 信息与情绪流经自身，接纳承受但不滞留，允许它按自己的方向流走 | `[M1-13]` |

**现场可做的物理演示**：让学员双脚并拢站立 → 轻推即倒；再双脚分开、放松核心 → 推力被吸收，偏移后能快速回中。`[M1-13]`

## 四、本质：流经而不成为

> 「客户的情绪也好，所有的信息也好，只是**流经**你，你却不成为，以此保持中正稳定。」`[M1-13]`

三个可检验的特征：

1. **扎根**：有自己的中心，不随外部波动漂移
2. **流动**：不是僵硬的墙，能弯曲、能吸收
3. **回弹**：被推偏之后能快速回到中心

## 五、能量场模型（诊断用）

理想状态下，个人能量场是**超顺滑、纯净**的——此时外来的波动很容易被识别为「这是他带来的」，而不是「我的」。`[M1-13]`

### 五层不稳定因素（从内到外，会叠加共振）

| # | 不稳定源 | 机制 |
|---|---|---|
| 1 | **未被察觉/未被满足的需求** | 能量场已有波动 → 客户带来同类议题时发生**共振** → 分不清哪些情绪是自己的 |
| 2 | **价值观无法践行** | 看重的价值长期被压制 → 遇同类议题即被触发，无法中立 |
| 3 | **生活失衡** | 常年奔波、私人生活被工作占满 → 能量场偏离静定，没有多余空间留给客户 |
| 4 | **身体状态** | 不运动、饮食睡眠不规律 → 疲惫叠加，进一步放大不稳 |
| 5 | **财务不稳** | 工作量大但收支不平衡 → 叠加后一点点风吹草动就被带偏 |

> 关键机制：**共振**。自身已有的波动 × 客户的同类波动 = 无法区分自我与他人。这是教练失去中正的真正原因，不是"技巧不够"。`[M1-13]`

## 六、六步清理（搭建路径）

逐步拆解、逐个清理，最终把调整变成**支持自己的新习惯**：`[M1-13]`

1. **梳理妥协事项** —— 列出正在忍耐/凑合的事，释放掉就会立刻感觉好很多
2. **识别并满足真实需求** —— 先识别，再逐步满足
3. **对齐价值观** —— 调整到按自己价值观生活的状态
4. **调整生活平衡** —— 找到失衡点做优化
5. **改善身体状态** —— 更好地照顾身体（运动、饮食、睡眠）
6. **梳理金钱关系** —— 让财务进入和谐状态

### 入口模块：停止凑合

核心稳定性内容分三个模块，**第一模块从「停止凑合」开始**（所有步骤写在配套的核心稳定性手册里）。`[M1-13]`

**当日作业（原版）**：在手册「停止凑合」板块选一个领域（工作/关系/生活等），**列出至少 10 件正在妥协凑合的事**，然后对其中一件采取行动，次日在助教小组汇报感受。`[M1-13]`

**作业示例**：小到修漏水的水龙头、擦掉墙上的指印；大到发现房子地段不对，决定卖掉换地段——但只需走出**第一步**，比如打电话给中介做估价。`[M1-13]`

## 七、常见误解（务必纠正）

**误解 1：核心稳定性 = 假装禅意**
不是。不需要故作淡定、用治疗师的语调说话，也不需要压抑天性。
> 「核心稳定性不是假装禅意，而是关于**全然活出来**。」`[M1-13]`

**误解 2：稳定 = 僵硬不动**
不是。恰恰相反——**越稳越灵活**。真正稳的人能弯曲、能吸收、能回弹。

**误解 3：稳定 = 压抑情绪**
不是。压抑是"没有反应"，稳定是"有反应但不被带走"。

**误解 4：稳定 = 要变得和老师一样**
不是。有人热爱冒险、需要多样性，有人喜欢安静——**只要清晰什么对自己重要，并按自己的方式活出来，就能获得稳定的能量场**。`[M1-13]`

## 八、教练视角的关键提醒

- 有大量未完成事件时，**即使发问和聆听都做得很好，对方依然动不了**——像被粘在原地。这时技术不是瓶颈，**未完成事件才是**。`[M2-06]`
- 教练自己能量场不稳，就**没有多余空间留给客户**。所以核心稳定性不是"额外修养"，是执业前提。`[M1-13]`
- 舒服是会扼杀成长的温柔乡。核心稳定性练习过程不容易，但成果一定让人满意。`[M3-39]`
