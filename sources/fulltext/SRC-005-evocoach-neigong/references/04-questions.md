## 一、识别线索表（最重要的一张表）

听到/看到这些信号时，可以直接跳到对应判断。**这张表是"从症状到源头"的实际入口。**

| 观察到的信号 | 大概率是 | 干预方向 |
|---|---|---|
| 反复重复同一个故事 | **未完成事件** | 三选一完结法 |
| 不停抱怨、指责他人 | **未完成事件** | 三选一完结法 |
| 说要做但一直没做 | **未完成事件**（曾自我宣告） | 三选一完结法 |
| 发问聆听都到位，对方依然动不了 | **未完成事件**（"像被粘住"） | 停止追技巧，转查未完成事件 |
| 说「我感受不到情绪」 | 情绪压抑模式的**症状** | 不跳解决方案，先找模式源头 |
| 列了计划一直推迟 | 长期凑合耐受 | 停止凑合 · 立刻行动 |
| 什么请求都答应、身心紧绷 | 边界缺失 | 边界三问 |
| 边界清楚但寸步不让 | 边界僵化（水泥墙） | 练灵活接纳 |
| 对某人长期积累愤怒却假装正常 | 边界模糊 + 情绪堆积 | 边界 + 未完成事件并行 |
| 一点风吹草动就被带偏 | 多个不稳定因素**叠加共振** | 六步清理 |
| 成长很快但感觉要塌 | 核心不稳 | 先补根，再谈成长 |

> 判据来源：`[M1-13]` `[M1-15]` `[M2-06]` `[M3-39]`

## 二、提问库（按阶段）

### 阶段 1 · 定位卡点

- 「现在什么在拖着你？」
- 「到底什么东西在拖拽着我们？」`[M2-06]`
- 「有什么是当下此刻就在你内在、很鲜活地存在着的？」`[M2-06]`
- 「特别想做但一直没做、而且它还在影响着你——到底是什么？」`[M2-06]`
- 「有哪些很重要的未完成的东西，真的在卡住你？」`[M2-06]`

### 阶段 2 · 找源头

- 「你到这个议题的关系里，现在处在哪儿？」`[M2-06]`
- 「这件事对你真正重要的地方是什么？」
- 「如果它一直不解决，你付出的代价是什么？」
- 「什么时候你第一次形成了这个应对方式？」

### 阶段 3 · 促成承诺

- 「有什么是你投入承诺、要去做到的？」`[M2-06]`
- 「你打算什么时候做？怎么算完成？」
- 「一到两件——你选哪件让它真的发生？」`[M2-06]`

> 收尾三问（讲师原话风格）：「清晰吗？容易吗？理解起来怎么样？」`[M2-06]`

### 边界专用三问

1. 「你接纳的到底是什么？」
2. 「它支持你的生命吗？」
3. 「你身体当下的反应是什么？」`[M1-15]`

### 一个高频误用提醒

「我要如何进化，成为最佳版本的自己？」是**方向性问题**，适合阶段性回望，不适合在卡点当下追问——它会把人推向未来，反而脱离当下。`[M2-06]`

## 三、成为进阶教练要放下的 7 类认知包袱

按原课程清单。**这是教练自己的功课，不是给来访者的。** `[M3-39]`

1. 固有的「什么是对/错」的知识结构
2. 对客户的**无意识评判**
3. 对客户**成果的执着**
4. 「每次约谈必须拿到突破」的要求
5. 「必须完全理解客户故事」的执念
6. 「必须把教练做对」的完美要求
7. 「必须让客户一直开心 / 必须共情感受客户痛苦」

> 放下这些，教练会更容易进入顺畅感。`[M3-39]`

---

## 四、成为专业教练要聚焦的 4 项

1. **创造有心理安全感的空间** —— 让客户愿意真实分享，同时保持临在
2. **加入轻松感与幽默感** —— 不把成长问题过度严肃化；「不要老是负重前行，而是需要轻松地应对」
3. **有勇气探索阴影部分** —— 不能只追求表面的开心快乐
4. **信任自身直觉** —— 给直觉留表达空间，保持呼吸觉察，身体放松

**底层支撑**：日常练习冥想与体育锻炼，保持稳定强大的能量状态——既支持自己也支持客户；保持场域的开放性，让客户能发挥自身潜能；以身作则展现对生活的激情。`[M3-39]`

## 五、教练状态自检（陷入卡顿时用）

逐条过一遍：

- [ ] 我是不是在**无意识评判**这个客户？
- [ ] 我是不是执着于他**必须拿到成果**？
- [ ] 我是不是在要求**这次必须突破**？
- [ ] 我是不是在追求**完全理解他的故事**？
- [ ] 我是不是在追求**把教练做对**（而不是做真）？
- [ ] 我是不是在**替他感受痛苦**？
- [ ] 我自己有没有**未完成事件**正在被这个议题共振？
- [ ] 我的**身体**现在是紧绷还是放松？

> 前 7 条任一命中，说明包袱还在；第 7、8 条命中，说明**你自己的能量场不稳**——先处理自己，再处理客户。`[M1-13]` `[M3-39]`
