# 方法 SOP

> 出处同概念卡。每个方法都给出**判断信号 → 步骤 → 教练动作 → 常见坑**四段。

---

## 方法一：三选一完结法（处理未完成事件）

**判断信号**：反复重复同一个故事 / 不停抱怨、指责他人 / 说要做但一直没做 / 明显"被粘住"推不动。
`[M2-06]`

**前置概念——什么是未完成事件（incompletions）**

> 属于过去、未被解决完结，但至今仍在**身体和情绪层面持续活跃**的想法、行为、情绪或**未兑现的承诺**。`[M2-06]`

- 判定钥匙：**你曾对自己宣告过要做，但没做**。宣告本身让它成为"未完成"。
- 积累效应：每个未完成事件像一块小石头，越积越多越重，持续消耗当下的能量。
- 它会拉扯你无法临在——**过去是记忆（已不存在），未来是投射（还没发生），唯一真实存在的是当下**。

**三个选项（让对方自己选，不替他选）**

| 选项 | 操作 | 关键要求 |
|---|---|---|
| ① **能做就立刻做** | 对自己做出承诺，选定时间动手完成 | 哪怕拖了十几年，做完就解除能量消耗 |
| ② **彻底放下不做** | 明确宣告"这件事我永远不做"，真正从心理释放 | **要放彻底**：它若再回来烦你，就再次放下 |
| ③ **授权他人完成** | 邀请别人帮你做 / 替你做 | 适合自己没时间或没能力的情况 |

> 原话：「这个房子里不是所有的东西都需要完美无瑕的，但**你得自己放了自己**。」`[M2-06]`

**教练动作**
1. 引导对方梳理生命各领域（物理环境 / 关系 / 工作 / 家庭 / 项目）的未完成事件
2. 写下 **1–2 个**真正卡住自己的（不要写一堆）
3. 在三个选项中明确选一个 + 给出完成计划
4. **担责跟进**：对方与教练做出承诺后，教练负责跟进到底——"这个机制会让教练辅导非常有力量"`[M2-06]`

**常见坑**
- 把它做成"待办清单管理" → 错了。重点是**解除能量牵引**，不是清空清单
- 让人一次完结十件事 → 错了。**选一到两件真的会发生的事**，其余直接宣告放下
- 忽略情绪层 → 有些未完成事件从童年一直挂到现在，完结本身就是深层情绪释放

**实例（讲师亲述）**：家里放器具房间的门装修时没装好，每次开门要花 5 分钟调整，拖了 **14 年**。一个月前终于修好，全家一起庆贺。要点：**做完结不必沉重，可以喜乐开怀、可以庆贺**。`[M2-06]`

## 方法二：停止凑合（立刻行动）

**判断信号**：列了计划一直推迟 / "等我有空了""等攒够劲了" / 物理空间或生活长期冗余混乱。`[M1-15]`

**底层逻辑**
> 物理空间的冗余混乱会带来**停滞感**；如果不完成基础清理，即使做再多教练辅导也还是卡滞状态。**清理是建立核心稳定性的基础工作。** `[M1-15]`

**步骤**
1. 选一个领域（工作 / 关系 / 生活 / 物理空间）
2. **列出至少 10 件正在凑合的事**（原版作业要求）
3. 选**一件**，只走出第一步
4. 完成一个小步，再接下一个小步，逐步积累行动势能

**立刻行动原则**
> 「未来一直不来。」「不要明天，不要等我有劲了，不要等到未来，主要是**立刻行动**。」`[M1-15]`

**大小事分流（关键判断）**

| 类型 | 处理方式 |
|---|---|
| **小事** | 像针灸一样**单点疏通**，做掉就行 |
| **大事**（如换房子、换工作） | 做成**长期项目**，拆解为任务逐步推进 |

> ⚠️ 核心澄清：「不将就的核心，**不是说把你已有的牢笼布置得更美好**。」如果确实需要大改变，就直接做出决定并推进准备；先整理好当下能整理的部分，攒够勇气与力量，再去迎接更大的改变。`[M1-15]`

**常见坑**：把整理变成"把现状装修得更舒服"，回避了真正需要的结构性改变。

## 方法三：边界三问 + 边界／标准分层

**判断信号**：什么请求都答应 / 身心紧绷、时间被占满 / 对某人长期积累愤怒却假装正常。`[M1-15]`

**第一步：理解边界的本质**

> 「边界本质是**你跟自己的一个约定**——你忍受什么、接受什么，边界在哪里，自己跟自己约定。」`[M1-15]`

不是用来约束别人的工具，是**自我约定**。

**第二步：边界 vs 标准（高阶）**

| | 边界 | 标准 |
|---|---|---|
| 定义 | 你和**自己**的约定 | 你和**未来自己**的合约 |
| 作用 | 守住底线（能接受什么） | 活出想要的生命状态 |
| 可协商性 | 可灵活 | **不可协商** |
| 示例 | — | 每周至少一天完全不工作，没达标下周补休两天；每天 9 点前吃够蛋白质 |

> 边界帮你守住底线，标准帮你活出想要的生命状态；慢慢会变成自然习惯，不再需要刻意坚持。`[M1-15]`

**第三步：处理"不敢设边界"的根源**

- 根源：原生家庭里父母自己也没学会设边界，无法做榜样 → 成年后没习得这项能力
- 认知纠正：**清晰沟通边界反而是对对方的尊重**；模糊的边界会让你积累愤怒、失望却假装正常，长期变成有毒的状态
- 中国家庭特例：不敢对父母设边界 → 把"清晰沟通"和"不尊重"解绑

**第四步：落地要配后果**

> 如果提出边界要求后**没有对应的行动支撑**，对方就不会相信你的边界。`[M1-15]`

**常见坑**：只提要求不给后果 → 边界形同虚设（离异家庭场景尤其明显）。

**从小培养（给家长的要点）**：孩子说 no 就不能亲；青少年关门独处是在**练习**设边界，不要打破。传统教育常教小女孩"不能说 no"——这是误区。`[M1-15]`

## 方法四：区分「接纳」与「将就」

**判断信号**：开始学接纳，但分不清是在成长还是在委屈自己；或者边界僵化成"水泥墙"。`[M1-15]`

**核心判别问句（三连）**
1. **你接纳的到底是什么？**（说清楚具体内容）
2. **它支持你的生命吗？**
3. **你身体当下的反应是什么？**（感受身体，再决定是否说 yes）

**结论**

> **接纳 = 主动选择的灵活；将就 = 被迫的忍受。** `[M1-15]`

**按阶段分流**

| 当前状态 | 该练什么 |
|---|---|
| 边界模糊、不会拒绝 | 先练**清晰界定** |
| 边界已清晰但僵化成水泥墙 | 练**灵活的边界**，主动接纳更多进入生活 |

**常见坑**：把"我很能忍"当成"我在接纳"——那通常是将就。

## 方法五：不跳解决方案（情绪议题专用）

**判断信号**：来访者说「我感受不到自己的情绪」。`[M1-13/15]`

**原则**：这只是**症状**。直接跳到"如何感受情绪"的解决方案，很难解决根本问题。

**正确路径**
1. 先帮对方看到**情绪压抑模式形成的源头**（例：小时候有情绪波动就会被惩罚 → "不发出声音、没有情绪波动才安全"）
2. 再调整思维与行为模式

> 来访者本身就活在"情绪是危险、无用"的认知黑匣子里，**根本不知道自己身处黑匣子**，自然找不到答案。`[M1-13]`

**配套概念**：认知滤镜——童年经验叠加形成的滤镜，扭曲了看世界的方式，而人不会质疑自己看到的内容（如同没戴过眼镜的人以为树就是一团绿色）。`[M1-13]`

**现场可用**：情绪处理属高阶内容，需班级能量匹配才开展；带领者需提前声明"这不是疗愈，我也不是疗愈师"，用**完成未完成事件**的方式处理卡住的能量；并要求学员**先自己用过，再考虑用在来访者身上**。`[M1-13]`
