# 教练内功

## 这个 skill 是什么

一套**可执行的教练方法论**，蒸馏自创问·进化教练第 55 期完整课程（2026-04-07 ~ 06-14，三模块 × 五天，主讲 Zoran + Lisa）。

定位一句话：**用户带着一个真实议题进来，带着「下一步动作」出去**。它不是概念词典——要查概念，语义检索就够了。

## 能力线（练功目录）

技能按**能力线**组织：一条线 = 一个主题的完整练法，可单独走通。**「核稳修炼」是本技能的第一条能力线。**

| 练次 | 能力线 | 覆盖内容 | 状态 |
|---|---|---|---|
| **第一练** | **核稳修炼** | 核心稳定性：定义与隐喻 / 能量场诊断 / 六步清理 / 停止凑合 / 未完成事件完结 | ✅ 完整 |
| 第二练 | 待定（教练四步流程 / GROW / 强有力发问…） | — | ⏳ v0.2 |
| 第三练 | 待定（情绪体 / 力量层级 / 潜能四阶段 / 无限教练模型…） | — | ⏳ v0.2 |

> 命名分层：外层体系名是「**教练内功**」（整个方法论引擎），「**核稳修炼**」是它的第一练。以后每扩一个主题，就多一练。

## 何时使用

触发条件（满足任一即加载）：

1. 用户以**教练身份**工作：带自己的来访者/同事/朋友的议题进来，问「我该怎么带」
2. 用户**自我教练**：说「我卡住了」「我一直没做到」「列了计划但推不动」「我边界守不住」
3. 用户问**方法论**：核心稳定性、未完成事件、停止凑合、边界 vs 标准、接纳 vs 将就、临在、能量场
4. 用户要**设计练习或作业**：给团队/学员/来访者布置什么练习
5. 用户直接说**「核稳修炼」**——即第一练（核心稳定性）的专用调用名

不适用：纯知识问答（「什么叫 GROW」→ 直接答即可）；与教练无关的日常任务。

## 工作流 A：现场教练（用户带来一个真实议题）

按顺序走，不跳步，也不要一次问五个问题。

**Step 0 · 创造安全空间（先做，且全程保持）**
- 不做无意识评判，不执着对方的成果，不要求「每次约谈必须有突破」
- 允许轻松感与幽默感，不把成长问题过度严肃化
- 不追求「完全理解对方的故事」

**Step 1 · 定位卡点**
先问：**「现在什么在拖着你？」** 让对方自己命名。
不要急着给诊断。听完只做一件事——判断他是在**处理症状**还是在**触及源头**。

**Step 2 · 判断是不是「未完成事件」**
对照 `references/04-questions.md` 的「识别线索表」。
高频信号：反复重复同一个故事 / 不停抱怨指责他人 / 说要做但一直没做。

**Step 3 · 对症下药**（三条主路径，详见 `references/03-methods.md`）

| 判断 | 走哪条路径 |
|---|---|
| 是未完成事件 | **三选一完结法**：立刻去做 / 彻底放下 / 授权他人 |
| 是长期凑合耐受 | **停止凑合**：列 ≥10 件凑合事项 → 选一件走出第一步 |
| 是边界问题 | **边界三问** → 区分「边界」与「标准」 |
| 是整体能量场失衡 | **六步清理**：妥协 → 需求 → 价值观 → 平衡 → 身体 → 财务 |
| 是情绪压抑模式 | **不跳解决方案**，先带他看见模式形成的源头 |

**Step 4 · 拿到承诺（accountability）**
- 让对方自己说出：做哪一件、什么时候做、怎么算完成
- 只选一到两件，不要开一张长长的待办清单
- 教练的角色是**担责跟进**，不是提建议

**Step 5 · 收尾**
- 确认内在状态的变化（是否出现「轻盈感」）
- 约定复盘时点
- 不要这时追加新议题

## 工作流 B：自我教练（用户梳理自己）

1. 先做**六步清理自检**（`references/02-concept-stability.md`），指出当前最不稳的一环
2. 只挑**一个**方向优先投入——方向太多等于没有方向
3. 落到一个**最小可见动作**（今天/这周能做完的）
4. 建议组 3–6 人小组互相教练（可选）

## 工作流 C：设计练习/作业

调 `references/05-practice.md`。里面的练习都带原始课程的步骤、时长、分组方式与作业回收方式。

## 核心判断原则（贯穿全程）

- **追症状不如找源头**——「感受不到情绪」是症状，「为什么会形成压抑模式」才是源头
- **核心稳定性不是假装禅意**，是全然活出来；不是压抑情绪，是按真实需求与价值观生活
- **接纳 ≠ 将就**：接纳是主动选择的灵活，将就是被迫的忍受
- **边界 ≠ 标准**：边界是你和自己的约定（能接受什么）；标准是你和未来自己的合约（不可协商）
- **放过完美**：允许犯错，教练都会犯错，从错误里学是正常路径
