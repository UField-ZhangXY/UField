# UField 品牌与体裁

根据用户提供的 12 篇样板总结整理；样板原文未随本技能附带，不声称已独立复核样板、Logo 取色或微信客户端行为。

## 品牌与层级

主色 #018985（Teal）：章节标题、关键词、SVG 主线、表头、强调边框、主按钮。点缀 #EC9804（Amber）：数字徽标和次级强调，避免大面积使用。两者是品牌双色组合，不称为同色相。
背景：#EAF6F4、#CDEAE6、#E0F2F0；浅黄 #FEF3E2。
正文 #222（可用 #1a1a1a）；导语 #1a1a1a。灰度仅供辅助信息。

| 层级 | 字号 | 行高 | 样式 |
|---|---|---|---|
| 栏目标签 | 12px | 1.5 | 非粗体、弱化角标 |
| 图注/来源/署名 | 13px | 1.6 | 可用 #999，需检查可读性 |
| 正文/列表 | 16px | 1.9 | 列表项间距 10px |
| 导语 | 17px | 1.9 | 加粗 |
| 金句框 | 16px | 1.9 | 浅青底，内边距 16px 20px，局部加粗 |

| H1 | 22px | 1.5 | 居中、加粗、可换行 |

共六档：12/13/16/17/19/22。正文固定 16px；行高默认 1.9，紧凑工具手册可回退 1.8。强调用加粗与颜色。SVG 内文字用 #1a1a1a、#222、#444，不用 #666/#999。
此字号是账号设计规范，不把“低于 16px 导致所有正文被 iOS 自动放大”当作已验证技术事实。

## 工具/手册文

目标：给出可执行方法；短段、结构清楚、少装饰。
结构：`-- U型工具 --` → 主标题与版本 → 有来源时加视觉/拍摄署名 → 📚 分区 → 文末四件套。
按实际资料设置六类分区：操作手册、带领/相关视频、参考资料、过往案例、U型工具互链、我U话说。缺少视频或案例时不编造、不留空壳。
用加粗角色词引领定义；步骤用“第一步：名称（时长）”，子项用编号。
视频条目：名称、带领人/催化师、来源、时长；过往案例链接格式“作者 | 标题”。
文末：`撰文：张小永@UField` → 实际资料参考 → 社群口号 → 联系方式。署名应符合本次用户确认。
资料参考示例：`资料参考：U-School，https://www.u-school.org/`，仅实际引用时使用。

## 活动招募文

默认新版（2024–2026）；用户要求复刻时采用旧版。
标题例：`UField｜{活动名}-{期数系列}•{日期}`；特别场可用“源头相遇｜活动名•特别场（全国第X期）--副题”。变量必须来自本次素材。
骨架：U型理论背景 → 经核实的项目历史/数字 → 往期回顾 → 本期亮点 → 工作坊设计 → 收获 → 对象 → 欢迎加入 → 导师/共创团队 → 发起方 → 更多信息 → 署名。
- 背景可引用彼得·圣吉或奥托·夏莫，但仅在原文和出处可核实时使用直接引文，否则改述并标明来源。
- 项目历史样板提到 2019 年 3 月发起；只有与本次活动确属同一项目且资料支持时才沿用。期数、城市数、参与人数、费用均需更新核实。
- 亮点一般 3–5 条，不为凑数虚构。工作坊五步骤：共同启动、共同感知、共同深潜、共同创造、共同迭代；环节按真实设计挑选。
- 时间、地点、费用、报名信息整行加粗；原价划线仅在有真实原价与优惠时使用。
- 新版精简导师卡：姓名、经核实的头衔、可核实的一句话；旧版可用“共创催化师”长履历、🚩 编号模块和真实口碑。
- 结尾 `* * *` 分隔，撰文、编辑/视觉、感谢按实际贡献列出。

可选署名格式：`✒️ 撰文：张小永`、`✒️ 撰文：张小永、大美`、`✒️ 撰文：杰哥、小永`、`✒️ 撰文：张小永、张晖`；`🎨 编辑：大美` 或实际视觉团队。
感谢示例：`❤️ 感谢：从2019年至今，UField场域中参与共创，互相陪伴，用心贡献的所有伙伴！`，须符合本次项目语境。

## 圆桌实录/深度汇谈

标题：`圆桌论坛 | {核心嘉宾}：{核心观点}` 或 `深度汇谈 | {嘉宾}：{主题}`。
结构：本文/图片来源与场次 → 时间场合背景 → 主持人与分享者列表 → 人物名片 → 对话正文 → 有材料时加入现场互动精华 → 压轴观点与 `* * *`。
发言用 `**姓名：**` 开场。首次出现定位身份与代表作；随后不重复履历。适度删口水话但保留故事细节，不改变说话人、观点与原话含义。
核心观点可以整段加粗；保留 16px，用颜色、留白区分发言标签与重点，不再额外放大。
无报名/二维码转化块，除非本次用户另有要求。素材不是实录时不能编造对话体冒充现场。
