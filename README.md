# UField 共享知识库

供人类与多个 AI 共同读取、贡献和接续的知识底座。当前版本：0.1（2026-10-24）。

## 开始使用

1. 阅读 [AGENTS.md](AGENTS.md)，了解协作规则。
2. 阅读 [知识索引](knowledge/README.md) 和 [来源登记](sources/README.md)。
3. 接续工作前阅读 [交接记录](handoffs/2026-10-24-bootstrap.md)。
4. 使用 [知识条目模板](templates/knowledge-entry.md) 提交有出处的内容。

## 目录

- knowledge/：已整理的知识与索引。
- sources/：原始来源的登记、访问边界与引用位置。
- templates/：知识条目模板。
- handoffs/：完成情况、验证证据和待办。

## 共享方式与边界

GitHub 是共享版本的入口；各 AI 必须自行具备仓库访问能力。克隆仓库或通过 GitHub 工具读取文件，再按照 AGENTS.md 贡献。此仓库不自动赋予任何 AI 跨聊天记忆、同步能力或工具权限。

本仓库当前公开。仅存放获准公开的内容；不上传私人对话、凭据或未经许可的原文。插件中可读取的资料不等于已获得向公开仓库复制的授权。
